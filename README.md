## Estrutura

- `index.html` — página principal
- `restaurante.html` — projeto 01
- `barbearia.html` — projeto 02
- `moda.html` — projeto 03
- `style.css` — estilos
- `script.js` — animações e ano automático
- `assets/` — imagens dos projetos
- `.nojekyll` — evita o processamento Jekyll desnecessário para este site estático
